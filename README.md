# QIAOQIAO

个人项目与实验代码的归档仓库。

## 说明

本仓库用于存放个人开发过程中的项目代码、脚本与实验记录，内容会随进度持续补充。

## 目录约定

| 目录 | 用途 |
| --- | --- |
| `docs/` | 设计说明与笔记 |
| `src/` | 主要代码 |
| `scripts/` | 辅助脚本与工具 |

> 目录会在有实际内容时逐步建立，当前仅有本说明文件。

## 使用方式

```bash
git clone git@github.com:renqiao821/QIAOQIAO.git
cd QIAOQIAO
```

## 许可

如无特别说明，仓库内代码仅用于个人学习与研究。
